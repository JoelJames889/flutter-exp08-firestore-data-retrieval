## ?? Aim & Objectives
Query and stream Firestore documents dynamically using StreamBuilder, equality filters, range bounds, and prefix search.

## ? Core Concepts & Widgets
StreamBuilder, where() Queries, Compound Filters, Realtime Streams

## ?? Repository Structure
- lib/main.dart - Complete standalone Flutter application source code.
- output_preview.html - Interactive browser preview simulating mobile output with print-ready lab record.
- RECORD.md - Complete laboratory report with Aim, Algorithm, Source Code listing, and Viva Voce questions.
- pubspec.yaml - Project dependencies and SDK requirements.

---

## ?? How to Run Locally

1. **Ensure Flutter is installed** and in your environment PATH:
   ``powershell
   flutter --version
   ``

2. **Fetch Dependencies**:
   ``powershell
   flutter pub get
   ``

3. **Run on Chrome / Emulator**:
   ``powershell
   flutter run -d chrome
   ``

4. **View Simulated Mobile Output Record**:
   Double-click \output_preview.html\ in your browser to inspect or print the lab submission record.
